Help & Documentation

🎯 Habit Tracking

What: Track daily habits with three states — ✔️ Done, ➖ Skipped, ❌ Missed.

Why: Consistent tracking builds self-awareness. Seeing your streaks grow is powerful motivation.

How: Click any cell in the calendar to cycle through states. Click the habit name to edit it.

💡 Tip: Right-click (or long-press) a cell to add a note for that day.

🔥 Streaks

What: Consecutive days of completing a habit.

Why: Streaks create momentum. Research shows that longer streaks become harder to break.

Rules:

  • ✔️ Done entries increment your streak.
  • ❌ Missed entries (or empty days) break your streak.
  • ➖ Skipped days are transparent — they neither break nor extend your streak.
💡 Edge case: If you disable the "Skip" toggle, skipped entries are hidden and treated as missed.

🎯 Goals

What: Set targets for each habit — daily, weekly, or custom periods.

Types:

  • Daily: Complete the habit every day.
  • Weekly: Complete X times per week (e.g., 3 times/week).
  • Custom: Complete X times every N days.

When to use: Not every habit needs to be daily. Use weekly goals for flexibility.

🌙 Day Extension

What: Extends "today" past midnight, up to 6 AM.

Why: If you stay up past midnight, you probably still think of it as "today." This setting respects that.

Example: With extension set to 3 AM, marking a habit at 2:30 AM counts for the previous calendar day.

⚠️ Note: This affects streak calculations too — consistently applied.

🎨 Themes

Available themes:

  • Light: Clean and bright, best for daytime use.
  • Dark: Easy on the eyes, good for evening use.
  • Pure Dark: True black backgrounds, OLED-optimized to save battery.
  • Ocean: Cool, calming blue tones.
  • Sunset: Warm, energetic purple-orange gradient feel.

Your theme choice is saved and persists across sessions.

💾 Data Management

Export: Downloads a ZIP file containing CSV files for all your data (habits, entries, goals, settings).

Import: Upload a CSV file to restore data. You'll see a preview before confirming.

💡 Tip: Regular exports protect against data loss. The app also auto-backs up before any repairs.

🔧 Database Repair

What: Self-healing mechanism for corrupted databases.

When to use: If the app behaves unexpectedly (missing data, errors), run an integrity check first.

Process:

  1. Creates a timestamped backup.
  2. Attempts to export and reimport all data into a fresh database.
  3. Verifies foreign key constraints.
  4. Reports results.
⚠️ Caution: Only use repair if integrity check fails. Backups are always created first.
