# Release Notes

## [v0.1.4] - 2026-02-14

### 🚀 New Features
- **Zero-Lag UX**: Optimistic UI updates ensure instant feedback on all interactions.
- **Three-State Tracking**: Track habits as Done (✔️), Skipped (➖), or Missed (❌).
- **Interactive Analytics**: Visual dashboard featuring activity trends, consistency charts, and detailed performance metrics.
- **Goal & Period Tracking**: Set flexible goals with daily, weekly, or custom frequencies.
- **Drag & Drop Reordering**: Direct manipulation of habit rows to prioritize your list.
- **5 Premium Themes**: Choose from Light, Dark, Pure Dark (OLED), Ocean, and Sunset.
- **Day Extension**: Adjustable "day boundary" logic for late-night tracking (e.g., extend day until 3 AM).
- **Confetti Celebration**: Physics-based confetti animations on habit completion.
- **Notes System**: Add context to any day with right-click notes; includes background sync.
- **Import/Export**: Full data portability with CSV export (ZIP) and restore functionality.
- **Self-Healing Database**: Robust integrity checks, automatic backups, and safe repair mechanisms.

### ⚡ Improvements
- **Responsive Calendar**: Monthly view with sticky headers and columns for easy navigation.
- **Squirky UI**: Modern, organic design language with glassmorphism and rounded aesthetics.
- **Tactile Controls**: Custom-built number spinners and segmented buttons replace standard browser inputs.
- **Cross-Platform Launchers**: One-click start scripts for Windows (`.bat`) and Linux/macOS (`.sh`).

- Comprehensive **README** detailing all features and setup.
- **Code & API Documentation**: Detailed technical guides for developers.
- **Design Philosophy**: Insights into the local-first, privacy-focused architecture.
